システム概要

📋 研修予約システムとは

研修生のシフト管理と予約受付を一元管理するWebアプリケーションです。

主な機能

お客様向け機能: - ✅ 5ステップの簡単予約フォーム - ✅ 予約番号による予約確認・キャンセル - ✅ スマホ対応レスポンシブデザイン - ✅ リアルタイムで予約可能時間を表示

管理者向け機能: - 📅 HOT PEPPER風月間シフトカレンダー - 📋 タイムライン予約管理 - 👥 研修生・メニューマスタ管理 - ➕ 手動予約追加機能 - 🔍 予約詳細確認・キャンセル

クイックスタート

🚀 初期セットアップ（5分で完了）

Step 1: Supabaseでデータベースを準備

Supabase Dashboard → SQL Editor で以下を実行：

-- 予約番号カラムを追加
ALTER TABLE reservation ADD COLUMN IF NOT EXISTS reservation_number TEXT UNIQUE;

-- 既存の予約に予約番号を付与
DO $$
DECLARE
  r RECORD;
  new_number TEXT;
BEGIN
  FOR r IN SELECT id FROM reservation WHERE reservation_number IS NULL LOOP
    LOOP
      new_number := LPAD(FLOOR(RANDOM() * 100000000)::TEXT, 8, '0');
      BEGIN
        UPDATE reservation SET reservation_number = new_number WHERE id = r.id;
        EXIT;
      EXCEPTION WHEN unique_violation THEN
        CONTINUE;
      END;
    END LOOP;
  END LOOP;
END $$;

登録例:

  6. 開始: 10:00

管理画面で確認: 1. 「予約管理」をクリック 2. タイムラインに予約が表示されることを確認 3. 予約ブロックをクリックして詳細確認

お客様向けマニュアル

🌐 アクセス方法

以下のURLにアクセスしてください：

https://training-reservation-v2.vercel.app

📅 新規予約の方法

Step 1: トップページ

  1. 「新規予約」をタップ

Step 2: メニュー選択

  1. 受けたいメニューをタップして選択
  2. メニューには所要時間が表示されています

Step 3: 研修生選択

  1. 担当してほしい研修生をタップして選択
  2. 選択したメニューを扱える研修生のみ表示されます

Step 4: 日付選択

  1. 予約したい日付をタップして選択
  2. 予約可能な日のみ表示されます（最大30日先まで）

Step 5: 時間選択

  1. 予約したい時間をタップして選択
  2. すでに予約済みの時間は表示されません

Step 6: お客様情報入力

  1. お名前を入力（例: 山田 太郎）
  2. 電話番号を入力（例: 090-1234-5678）
  3. 「予約を確定する」をタップ

Step 7: 予約完了

✅ 予約完了メッセージが表示されます

重要：予約番号（8桁）が表示されます - この番号は予約確認・キャンセル時に必要です - 必ずメモまたはスクリーンショットで保存してください

🔍 予約確認・キャンセルの方法

予約内容を確認する

  1. トップページで「予約確認・キャンセル」をタップ
  2. 予約番号（8桁）を入力
  3. 電話番号を入力（予約時と同じもの）
  4. 「予約を確認する」をタップ

予約内容が表示されます

  • 予約番号
  • 日時
  • 研修生
  • メニュー
  • お客様情報

予約をキャンセルする

  1. 予約内容確認画面で「予約をキャンセルする」をタップ
  2. 確認メッセージが表示されるので「OK」をタップ
  3. ✅ キャンセル完了

⚠️ 注意事項 - キャンセルした予約は元に戻せません - 再度予約する場合は、新規予約からやり直してください

❓ お客様向けよくある質問

Q1: 予約番号を忘れてしまいました

A: 予約番号がないと予約確認ができません。予約完了時に必ずメモを取るようにしてください。

Q2: 予約できる期間は？

A: 最大30日先まで予約可能です。

Q3: 予約時間を変更したいです

A: 一度キャンセルしてから、新規予約で希望の日時を選び直してください。

Q4: 電話番号を間違えて入力してしまいました

A: 予約確認時に正しい電話番号でログインできなくなります。店舗に直接お問い合わせください。

管理者向けマニュアル

⚙️ 基本設定

1. 研修生の登録

アクセス: 管理画面トップ → 「基本設定」

登録手順: 1. 「研修生管理」セクションを確認 2. 入力欄に研修生の名前を入力（例: 山田 太郎） 3. 「追加」ボタンをクリック 4. 登録された研修生が一覧に表示されます

削除方法: - 各研修生の右側にある「削除」ボタンをクリック - 確認メッセージで「OK」を選択

⚠️ 注意: 研修生を削除すると過去の予約データに影響する可能性があります

2. メニューの登録

アクセス: 管理画面トップ → 「基本設定」

登録手順: 1. 「メニュー管理」セクションを確認 2. メニュー名を入力（例: まつげパーマ＋眉カット） 3. 所要時間（分）を入力（例: 60） 4. 「追加」ボタンをクリック

表示/非表示の切り替え: - 「表示」「非表示」ボタンで切り替え - 非表示にしたメニューはお客様の予約画面に表示されません

削除方法: - 「削除」ボタンをクリック

3. メール通知設定（オプション）

  1. 「メール通知設定」セクションに移動
  2. 予約通知を受け取りたいメールアドレスを入力
  3. 「保存」ボタンをクリック

⚠️ 注意: 現在メール機能は無効化されています

📅 シフト設定

HOT PEPPER風カレンダーでシフトを設定

アクセス: 管理画面トップ → 「シフト設定」

月の切り替え

  • 画面上部の「◀ 前月」「次月 ▶」ボタンで月を切り替え

シフト入力方法

ステップ1: 日付セルをクリック

  • カレンダーの日付セルをクリック
  • モーダル（設定画面）が開きます

ステップ2: ステータスを選択

  • 出勤: この日に研修生が出勤
  • 休み: この日は休み
  • 未設定: シフト未定

ステップ3: 出勤の場合、時間枠を設定

時間枠の追加: 1. 「時間枠を追加」ボタンをクリック 2. 開始時刻を入力（例: 10:00） 3. 終了時刻を入力（例: 13:00） 4. この時間帯で扱うメニューを選択 5. 「保存」ボタンをクリック

予約可能時間の自動生成: - 選択したメニューの所要時間に応じて、予約可能な時間枠が自動的に生成されます - 例: 10:00-13:00、メニュー60分 → 10:00, 11:00, 12:00 が予約可能時間として生成

複数の時間枠を設定する例:

時間枠1: 10:00-13:00 → まつげパーマ＋眉カット（60分）
時間枠2: 14:00-18:00 → まつげパーマ（45分）、眉カット（30分）

カレンダー表示の見方

  • 出: 出勤日（クリックで詳細編集可能）
  • 休: 休み
  • -: 未設定

📋 予約管理

アクセス: 管理画面トップ → 「予約管理」

画面の見方

サマリーカード

  1. 本日のスケジュール
  2. 本日の予約件数を表示

  3. クリックするとタイムライン表示に切り替わります

  4. 本日の予約一覧

  5. 時刻、研修生、お客様名、メニューを一覧表示

週間予約状況

  • 今日から7日分の予約件数をグラフ表示
  • 日曜日は赤色で表示

タイムライン表示

日付選択: - 上部の日付入力欄で確認したい日を選択

表示内容: - 横軸: 時間（9:00〜19:00） - 縦軸: 研修生 - 予約ブロック: 色付きで表示

予約詳細の確認: 1. 予約ブロックをクリック 2. モーダルが開き、以下の情報が表示されます： - 予約番号 - 日時 - 研修生 - メニュー - お客様名 - 電話番号 - メールアドレス（登録されている場合）

予約のキャンセル: - 予約詳細モーダルの「この予約をキャンセル」ボタンをクリック

手動で予約を追加する

タイムラインから追加: 1. タイムライン表示で、空いているセルをクリック 2. 手動予約追加モーダルが開きます 3. 研修生と時刻が自動入力されます

入力項目: - 研修生（自動入力済み） - メニュー * - 開始時刻（自動入力済み） - お客様名 * - 電話番号 * - メールアドレス（任意）

完了: - 「予約を追加」ボタンをクリック - 予約番号が自動生成され、表示されます - この予約番号をお客様に伝えてください

リスト表示

切り替え: - 画面上部の「リスト」ボタンをクリック

表示内容: - 時刻 - 研修生 - メニュー - お客様名・電話番号

キャンセル: - 各予約の右側にある「キャンセル」ボタンをクリック

📊 運用フロー例

毎月の運用

1. 月初にシフトを設定 - 翌月のシフトをカレンダーに入力 - 研修生ごとに出勤日・時間枠を設定

2. 予約が入ったら確認 - 予約管理画面で本日・週間の予約を確認 - 必要に応じて研修生に連絡

3. 予約変更・キャンセル対応 - お客様から連絡があった場合、手動でキャンセル - 予約詳細画面から簡単にキャンセル可能

4. 手動予約の追加 - 電話予約などはタイムラインから手動で追加 - 予約番号をお客様に伝える

📱 日常の使い方

毎日やること

予約管理画面を確認 - 本日の予約件数・内容を確認 - 予約ブロックをクリックして詳細確認

毎月やること

予約変更・キャンセル時

お客様から連絡があった場合 1. 予約管理画面を開く 2. 該当の予約をクリック 3. 「この予約をキャンセル」ボタンをクリック

電話予約を受けた場合 1. タイムラインの空いているセルをクリック 2. お客様情報を入力 3. 「予約を追加」をクリック 4. 表示された予約番号をお客様に伝える

🎯 運用のコツ

✅ DO（推奨）

  • シフトは1ヶ月前に設定
  • 予約番号は必ずお客様に伝える
  • 毎朝、本日の予約を確認

❌ DON'T（非推奨）

  • 研修生やメニューの削除（過去の予約に影響）
  • 直接データベースを編集（管理画面を使用）
  • 予約番号を紛失（再発行不可）

トラブルシューティング

❓ よくある質問（管理者向け）

Q1: 研修生を削除すると過去の予約も消えますか？

A: データベースの設定により、関連する予約も削除される可能性があります。使用しなくなった研修生は削除せず、非アクティブ化することを推奨します（現在非アクティブ機能は実装されていません）。

Q2: 同じ時間に複数のメニューを受け付けたい

A: シフト設定で時間枠を追加する際、複数のメニューを選択できます。

Q3: 過去の予約は見れますか？

A: 日付を選択すれば過去の予約も確認できます。

Q4: 予約をキャンセルしたらお客様に通知されますか？

A: 現在、自動通知機能はありません。キャンセル時は別途お客様に連絡してください。

Q5: スマホでも管理画面は使えますか？

A: はい、レスポンシブデザイン対応済みです。ただしシフト設定などPC推奨の画面もあります。

🔧 トラブル対応

予約が表示されない

→ 日付が正しく選択されているか確認

お客様が予約できない

→ シフト設定がされているか確認
→ メニューが「表示」になっているか確認

予約番号がわからない

→ 予約管理画面から該当の予約を探してクリック

タイムラインがおかしい

→ ブラウザをリロード（F5キー）
→ キャッシュをクリア

⚠️ 重要な注意事項

予約番号について

  • 予約完了時に表示される8桁の番号
  • 予約確認・キャンセルに必須
  • お客様に必ず伝えてください
  • 紛失した場合は再発行できません

データの削除について

  • 研修生やメニューを削除すると過去の予約データに影響します
  • 削除ではなく「非表示」を推奨（メニューのみ対応済み）

メール機能について

  • 現在、メール通知機能は無効化されています
  • ドメイン認証が必要なため
